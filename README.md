# Walmart Supply Chain Optimizer

## About the Project

We are building an end-to-end supply chain decision-support system that uses historical retail sales data to help answer:

1. What products will each store need?
2. How much inventory should each store keep?
3. Which products are at risk of running out?
4. Which warehouse should supply each store?
5. What routes should delivery trucks take?
6. What will the transportation cost be?
7. What will the estimated carbon emissions be?

## Project Pipeline

Historical Sales Data
→ Demand Forecasting
→ Inventory Optimization
→ Stockout Prediction
→ Warehouse Allocation
→ Vehicle Routing
→ Cost & Carbon Analysis
→ Dashboard

## Data

We will begin with publicly available Walmart/M5 sales data.
